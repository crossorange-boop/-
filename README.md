# AI統合管制システム（Phase 1）

複数のAIエージェントに割り振った業務・プロジェクト・スケジュール・成果物を一元管理する Webアプリです。
Google Apps Script + Google Sheets で動作し、**追加の有料サービスは使いません**。定期処理は Google のサーバー上で動くため、PC を閉じていても動作します。

## 主な機能

- 総合ダッシュボード（件数・状態別内訳・AI別担当・期限超過・活動履歴・今日のレポート）
- プロジェクト／タスク（依存関係・状態管理・成果物登録）／スケジュール／成果物・承認
- AIエージェント管理（能力・稼働状態・利用制限）と作業待ちキュー（指示書のコピー）
- ルールベースの自動振り分け（AI停止時は利用待ちで保持し、復旧で自動再開）
- 定期処理：振り分け5分・期限確認15分・朝7時／昼13時／夕17時レポート・3時バックアップ
- 実行履歴・変更履歴・再実行・復元・割り振りルール編集・導入確認（自己診断）
- スマートフォン対応・ダークモード対応、権限（OWNER／EDITOR／VIEWER）

## 構成

```
src/        Google Apps Script に反映するコード（clasp push の対象）
  00〜11    設定・共通関数・データアクセス（Repository：将来 DB を差し替え可能）
  20〜29    業務サービス（プロジェクト・タスク・AI・成果物・承認・通知・設定・集計）
  30〜39    エンジン（状態遷移・振り分け・キュー・期限・依存・レポート・ルール）
  40        外部AI接続アダプター（Phase 2 で n8n・公式APIを追加）
  50〜53    定期処理・トリガー・バックアップ・システム情報
  60〜99    権限・API窓口・セットアップ・Webアプリ・自己診断
  ui/       画面（HTML/CSS/JavaScript）
test/       単体・結合テスト（Node）と画面テスト（ブラウザ操作）
tools/      画面のローカルプレビュー（模擬環境・サンプルデータ）
docs/       設計書・手順書
dist/       ブラウザだけで導入するためのまとめファイル（自動生成：node tools/build-bundle.js）
```

## 開発者向け

```bash
npm install
```
```bash
npm test        # 単体・結合テスト
```
```bash
npm run e2e     # 画面の結合テスト（ブラウザ操作）
```
```bash
npm run build   # dist/ のまとめファイルを作り直す（src/ を変更したら必ず実行）
```
```bash
npm run preview # サンプルデータ入りの画面プレビュー（http://localhost:8787、Googleには接続しない）
```

認証情報（`.clasprc.json`）と `.clasp.json` はリポジトリに含めません。
