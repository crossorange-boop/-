# ブラウザだけで導入する（clasp を使わない方法）

コマンド操作をせず、Chrome だけで導入する方法です。Chrome のサイドバーで動く Claude（Claude in Chrome）に、
下の「指示文」を貼り付けて任せることもできます。

## 使うファイル（GitHub の `ai-control-system` ブランチ、`dist/` フォルダ）

| ファイル | Apps Script エディタでの名前 | 内容 |
| --- | --- | --- |
| `dist/Code.gs` | `コード.gs`（最初からあるファイルを置き換え） | サーバー処理一式（src/*.gs を1つに連結） |
| `dist/ui_index.html` | `ui/index`（HTML ファイルを新規作成） | 画面一式 |
| `dist/appsscript.json` | `appsscript.json` | タイムゾーン・権限・公開範囲 |

- 中身は `src/` と同じで、自動生成しています（`node tools/build-bundle.js`）。テストで同一であることを確認しています。
- 更新するときは、同じ3ファイルを貼り直してから、デプロイを新しいバージョンに更新します。

## 手作業で行う場合の手順

1. https://script.google.com/home/usersettings … 不要（clasp を使わないため Apps Script API の有効化は不要）
2. https://script.google.com/home →「新しいプロジェクト」。左上の「無題のプロジェクト」を「AI統合管制システム」に変更。
3. 左の歯車「プロジェクトの設定」→「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェック。
4. 左の「エディタ」に戻り、`appsscript.json` を開いて中身を全部消し、`dist/appsscript.json` の内容を貼り付けて保存。
5. `コード.gs` を開いて中身を全部消し、`dist/Code.gs` の内容を貼り付けて保存。
6. 「ファイル」の「＋」→「HTML」→ 名前に `ui/index` と入力 → 中身を全部消し、`dist/ui_index.html` の内容を貼り付けて保存。
7. 関数 `setupSystem` を選んで実行 → 権限を確認して許可。
8. 関数 `setupTriggers` を選んで実行。
9. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行：自分、アクセス：自分のみ → デプロイ → URL を控える。
10. URL を開き「設定・ログ → システム情報 → 点検する」。

GitHub のファイル画面では、右上の「Copy raw file」（コピーのアイコン）で全文をコピーできます。

## Chrome サイドバー（Claude in Chrome）に貼る指示文

次の枠の中をすべてコピーして、Chrome サイドバーの Claude に貼り付けてください。

```text
あなたは私の Chrome を操作して、Google Apps Script で作った「AI統合管制システム」を私の Google Workspace アカウントに導入するアシスタントです。
以下の手順を順番に、1つずつ確認しながら進めてください。各手順の最後にある「確認」が満たされない場合は、先へ進まずに画面の状況を報告して指示を待ってください。

# 守ること
- パスワードの入力、2段階認証、Google の「許可」ボタン（権限の承認）は、私が自分で行います。その画面になったら止まって私に知らせてください。
- 「デプロイ」ボタンを押す前に、設定内容（実行ユーザー・アクセスできるユーザー）を私に見せて、了承を得てから押してください。
- 指定したファイル・プロジェクト以外は変更しないでください。既存の Apps Script プロジェクトやドライブのファイルを削除・編集しないでください。
- 共有設定や Google Workspace の管理設定は変更しないでください。
- 新しいタブで作業し、私が開いている他のタブは操作しないでください。

# 使うファイル（GitHub。私のアカウントでログイン済みの前提）
- A: https://github.com/crossorange-boop/-/blob/ai-control-system/dist/appsscript.json
- B: https://github.com/crossorange-boop/-/blob/ai-control-system/dist/Code.gs
- C: https://github.com/crossorange-boop/-/blob/ai-control-system/dist/ui_index.html
ファイルの全文コピーは、GitHub のファイル画面右上の「Copy raw file」ボタン（コピーのアイコン）を使ってください。手で入力したり、画面から読み取って打ち直したりしないでください（ファイルが大きいため、必ずコピー＆貼り付けで行うこと）。

# 手順
1. 新しいタブで https://script.google.com/home を開き、右上のアカウントを私に伝えて、導入先として正しいか確認を取る。
   確認：私が「このアカウントでよい」と答えた。

2. 「新しいプロジェクト」を作成し、左上のプロジェクト名「無題のプロジェクト」を「AI統合管制システム」に変更する。
   確認：プロジェクト名が「AI統合管制システム」になっている。

3. 左側の歯車アイコン「プロジェクトの設定」を開き、「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェックを入れる。左側の「<>（エディタ）」に戻る。
   確認：ファイル一覧に appsscript.json が表示されている。

4. 別タブでファイル A を開き「Copy raw file」でコピー。エディタで appsscript.json を開き、エディタ内をクリックして全選択（Windows は Ctrl+A、Mac は Command+A）→ 貼り付け（Ctrl+V / Command+V）→ 保存（Ctrl+S / Command+S）。
   確認：内容に "timeZone": "Asia/Tokyo" と "access": "MYSELF" が含まれ、保存後にエラー表示がない。

5. ファイル B を開き「Copy raw file」でコピー。エディタで「コード.gs」（英語表示なら Code.gs）を開き、全選択 → 貼り付け → 保存。
   確認：1行目付近に「AI統合管制システム v」と「まとめファイル」があり、ファイルの末尾が「function runSelfCheck() {」で始まる関数で終わっている。保存時に構文エラーが出ていない。

6. ファイル一覧の「＋」→「HTML」を選び、ファイル名に ui/index と入力して作成（拡張子 .html は自動で付く）。ファイル C を開き「Copy raw file」でコピーし、作成した ui/index.html を全選択 → 貼り付け → 保存。
   確認：ファイル一覧に「ui/index.html」があり、先頭が「<!DOCTYPE html>」、末尾が「</html>」になっている。

7. エディタ上部の関数選択プルダウンで「setupSystem」を選び「実行」を押す。「承認が必要です」が出たら「権限を確認」を押し、そこで止まって私に知らせる（アカウント選択・「詳細」→「安全ではないページに移動」・「許可」は私が行う）。私が許可したら、実行ログに「実行完了」が出るまで待つ。
   確認：実行ログに「実行完了」があり、エラーがない。ログに表示された spreadsheetUrl を私に伝える。

8. 関数選択で「setupTriggers」を選び「実行」。完了したら左側の時計アイコン「トリガー」を開く。
   確認：トリガーが6件（jobQueueCheck, jobDeadlineCheck, jobDailyPlan, jobMiddayCheck, jobDailySummary, jobBackup）登録されている。エディタに戻る。

9. 右上の「デプロイ」→「新しいデプロイ」。「種類の選択」の歯車から「ウェブアプリ」を選ぶ。説明に版番号（Code.gs の1行目にある v○.○.○）、「次のユーザーとして実行」は「自分」、「アクセスできるユーザー」は「自分のみ」にする。ここで設定内容を私に見せて了承を得てから「デプロイ」を押す。
   確認：ウェブアプリの URL（末尾が /exec）が表示された。その URL を私に伝える。

10. 新しいタブでウェブアプリの URL を開く。ダッシュボードが表示されたら、メニューの「設定・ログ」→「自動処理」タブで「今すぐバックアップ」を押す。次に「システム情報」タブを開き、ページ下部の「点検する」を押す。
    確認：総合判定と各項目の結果を、そのまま私に報告する。

# 困ったとき
- 「ファイルを開けません」「Sorry, unable to open the file」と出た場合：複数の Google アカウントにログインしていることが原因の場合があります。私に知らせてください。
- 貼り付けが途中で切れた、または保存時にエラーが出た場合：そのファイルを全選択して消し、コピーからやり直してください。2回失敗したら私に知らせてください。
- 想定と違う画面やメッセージが出た場合：操作を止め、表示内容をそのまま報告してください。

最後に、作業結果を次の形でまとめて報告してください。
- 導入したアカウント：
- データベース（スプレッドシート）の URL：
- ウェブアプリの URL：
- トリガー：6件登録済み／それ以外
- 点検の結果：
```

## 更新のとき：Chrome サイドバーに貼る指示文

コードが更新されたら（GitHub の `dist/` が新しくなったら）、次の枠の中を Chrome サイドバーの Claude に貼り付けます。
**ウェブアプリの URL は変わりません。** データもそのまま残ります。

```text
あなたは私の Chrome を操作して、導入済みの「AI統合管制システム」（Google Apps Script）を最新版に更新するアシスタントです。
各手順の「確認」が満たされない場合は先へ進まず、画面の状況を報告して指示を待ってください。

# 守ること
- 新しいプロジェクトは作らないでください。既存の「AI統合管制システム」プロジェクトだけを更新します。
- 「新しいデプロイ」は使わないでください（URL が変わってしまうため）。必ず「デプロイを管理」で既存のデプロイを更新します。
- Google の「許可」画面、パスワード入力、デプロイ更新の最終ボタンは、私に確認してから進めてください。
- 指定以外のファイル・プロジェクト・共有設定は変更しないでください。新しいタブで作業してください。

# 使うファイル（GitHub。全文コピーはファイル画面右上の「Copy raw file」ボタンで行い、手入力しないこと）
- A: https://github.com/crossorange-boop/-/blob/ai-control-system/dist/appsscript.json
- B: https://github.com/crossorange-boop/-/blob/ai-control-system/dist/Code.gs
- C: https://github.com/crossorange-boop/-/blob/ai-control-system/dist/ui_index.html

# 手順
1. ファイル B を開き、1行目付近の「AI統合管制システム v○.○.○」の版番号を読み取って私に伝える。
   確認：版番号を伝えた。

2. 新しいタブで https://script.google.com/home を開き、プロジェクト「AI統合管制システム」を開く。
   確認：エディタに コード.gs（または Code.gs）、ui/index.html、appsscript.json がある。

3. ファイル A をコピーし、エディタの appsscript.json を全選択（Ctrl+A／Command+A）→ 貼り付け → 保存（Ctrl+S／Command+S）。
   確認：保存後にエラー表示がない。

4. ファイル B をコピーし、コード.gs を全選択 → 貼り付け → 保存。
   確認：1行目付近の版番号が手順1と同じで、末尾が「function runSelfCheck() {」で始まる関数で終わり、構文エラーがない。

5. ファイル C をコピーし、ui/index.html を全選択 → 貼り付け → 保存。
   確認：先頭が「<!DOCTYPE html>」、末尾が「</html>」。

6. 関数選択で「setupSystem」を選んで実行（既存データは変更されず、新しい設定項目があれば追加されるだけの安全な処理）。
   「承認が必要です」が出た場合は止まって私に知らせる（権限が増える更新のときだけ出ます）。
   確認：実行ログに「実行完了」があり、エラーがない。

7. 右上の「デプロイ」→「デプロイを管理」を開き、既存のウェブアプリのデプロイを選んで鉛筆アイコン（編集）を押す。
   「バージョン」を「新バージョン」にし、説明に手順1の版番号を入力する。ここで内容を私に見せ、了承を得てから「デプロイ」を押す。
   確認：更新が完了し、ウェブアプリの URL が以前と同じ（末尾 /exec）。

8. ウェブアプリの URL を開き（開いていれば再読み込み）、左下（スマホでは「メニュー」画面の下）に表示される版番号が手順1と同じことを確認する。
   メニューの「プロジェクト」「タスク」「作業待ちキュー」を順に押し、画面が正しく切り替わる（真っ白にならない）ことを確認する。
   最後に「設定・ログ」→「システム情報」→「点検する」を押す。
   確認：版番号・画面の切り替え・点検結果を私に報告する。

最後に次の形で報告してください。
- 更新した版：
- 画面の切り替え：正常／異常（どの画面か）
- 点検の結果：
```

## 毎朝の確認：Chrome サイドバーに貼る指示文（読むだけ・変更しない）

`（ウェブアプリのURL）` の部分を、ご自身の URL（末尾 /exec）に置き換えて使います。

```text
次のウェブアプリを開いて、今日の状況を読み取り、要点を日本語で短くまとめてください。画面上のボタンは押さず、データは一切変更しないでください（タブの切り替えと画面の移動だけ行ってよい）。
URL：（ウェブアプリのURL）

1. ダッシュボードで、件数（プロジェクト・タスク・期限超過・要承認）と、「今日のレポート」の朝・昼・夕のうち最新のものを読む。
2. 「作業待ちキュー」で、担当ごとの件数と、「担当割当済み」で指示書が未入力のタスクを読む。
3. 「成果物・承認」で、承認待ちと確認待ちの成果物を読む。
4. 通知（ベルのアイコン）の未読を読む。

まとめ方：
- 今日やるべきこと（期限超過・今日期限・承認待ち）を優先度順に最大5件
- 止まっているタスク（利用待ち・前提待ち・失敗）とその理由
- 指示書が未入力で、すぐ依頼できないタスク
- 気になる点があれば一言
```

## 開発・修正の依頼もブラウザで

コードの修正や機能追加の依頼は、デスクトップアプリを使わなくても、Chrome で https://claude.ai/code を開けば同じように依頼できます。
修正が終わると GitHub の `dist/` が更新されるので、上の「更新のとき」の指示文で反映します。
